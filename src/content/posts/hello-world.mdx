This is a **seed post** used to confirm the Astro Content Collections pipeline works end-to-end before Phase 3 migration begins.

## Why this exists

Phase 2 of the rebuild needs to prove the following work together:

- MDX content authoring with frontmatter validation via Zod
- Dynamic routing under `/blog/[...slug]`
- Layout, header, footer, and typography rendering as expected

Real posts arrive in [Phase 3](/blog/) once the WordPress migration script is written.

## What replaces this

The 42 posts pulled from mujofitness.com's REST API become MDX files under `src/content/posts/`, with the frontmatter fields defined in `src/content.config.ts`.
